# TaskMate
✅ TaskMate – React To-Do App

TaskMate is a simple and modern to-do list application built using React. It helps users manage daily tasks by allowing them to add, complete, delete, and track progress in an easy and user-friendly way.

🚀 Features

Add new tasks

Mark tasks as completed

Delete individual tasks

Clear all tasks

Progress tracker showing completed tasks

Data persistence using localStorage

Clean and responsive UI

🛠️ Tech Stack

React JS

JavaScript (ES6)

HTML5

CSS3

📂 Project Structure

Components/TaskForm – Add new tasks

Components/TaskList – Display all tasks

Components/TaskItem – Individual task item

Components/ProgressTracker – Shows task completion progress

App.jsx – Main application logic

🧠 Concepts Used

React Functional Components

React Hooks (useState, useEffect)

Props and State management

Conditional rendering

Array methods (map, filter)

localStorage for data persistence
